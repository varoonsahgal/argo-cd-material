# Concept Guide Template

Use for any outline session that has **no** dedicated Lab. This file is the participant's only explanation of the concept, so it must stand entirely on its own — see [content contract](../../../standards/content-contract.md).

## Title

## Why this matters
A concrete operations scenario that motivates the concept before naming it.

## Plain-language mental model
An analogy or everyday comparison introduced before any formal terminology.

## Vocabulary
Every new term used in this guide, defined in one plain sentence before it is used functionally. Expand every acronym on first use.

## Visual
A diagram (see `visual-teaching`) and/or a screenshot (see `screenshot-capture`) that makes an otherwise invisible process (reconciliation, ownership, topology) concrete.

## Worked walkthrough
A fully narrated example the participant follows along with — screenshots and commands where relevant, explained step by step. Nothing is left blank here; this is not an exercise.

## Quick Checks
2-4 short questions that test understanding, answered inline immediately after (these are ungraded comprehension checks, not exercises).

## Try It Yourself
One short (5-10 minute), clearly optional hands-on micro-task that reinforces the concept without requiring the full lab environment setup a dedicated Lab would need.

## Common misconceptions
Name the wrong mental model explicitly, then correct it.

## Key takeaways
3-5 concise, memorable conclusions — the ones a participant should still remember tomorrow.

## Transition
One line connecting to what comes next.
