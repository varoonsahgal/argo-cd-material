# Assessment Designer

Read [question patterns](./question-patterns.md) for reusable formats.

## Procedure
1. Start from the learning objective.
2. Decide what evidence would prove understanding.
3. Prefer a scenario, prediction, diagnosis, comparison, or explanation task over a definitional one.
4. Include plausible distractors based on common Argo CD misconceptions when using multiple choice.
5. Provide answer rationale, not only the correct option.
6. Keep any required reading of CLI/UI output purposeful; do not make output-parsing itself the main difficulty unless that is the objective.
7. Mix immediate checks with later retrieval of earlier concepts (e.g., revisit sync-vs-health status during the capstone).

## Strong assessment rule
Ask: "Could someone answer this by memorizing one sentence?"
If yes, redesign it unless recall is genuinely the objective.
